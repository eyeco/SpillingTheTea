# Firmware Code for 4-Button User Interface

VS Code project for [PlatformIO](https://platformio.org/).
Implementation of FSR sensor sampling (up to 16) via [Sparkfun CD74HC4067](https://www.sparkfun.com/sparkfun-analog-digital-mux-breakout-cd74hc4067.html) multiplexer and data transmission via [sqid](https://github.com/eyeco/sqid) serial protocol.

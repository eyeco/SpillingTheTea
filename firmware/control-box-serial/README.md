# Firmware Code for ControlBox

VS Code project for [PlatformIO](https://platformio.org/).
Implementation of [Festo VEMP-BS-* 8065735 K502 piezo valve](https://www.festo.com/de/en/a/8065735/) control via [Gravity GP8403 2-Channel I2C DAC](https://wiki.dfrobot.com/dfr0971/) and sampling of [Amphenol All Sensors ELVH-030G-HAND-C-PSA4 SPI pressure sensors](https://allsensors.com/en/products/elvh-030g-hand-c-psa4), as well as data transmission via [sqid](https://github.com/eyeco/sqid) serial protocol.
